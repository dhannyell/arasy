# Credits

## Go Mono (embedded default font)

Go Mono, designed by Bigelow & Holmes, is the embedded default font used by the
engine for `FontID(0)` when no game font is declared. It is distributed under
the BSD-3-Clause license via `golang.org/x/image/font/gofont/gomono`.
